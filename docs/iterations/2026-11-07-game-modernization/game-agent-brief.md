## Instructions to the worker

Work only on the assigned title. Read the repository AGENTS.md, mac-game-modernization skill, tuning reference and supplied handoff. Do not rely on an inherited copy of the parent conversation.

Establish the baseline, test targeted candidates, validate observed gameplay and produce a reviewable change. Follow the coordinator's serial benchmark procedure; no other game, heavy build or conversion should run during timing captures. Do not spawn additional agents, commit/push, change other titles' defaults or deploy. If a necessary shared change falls outside the supplied scope, send the coordinator the evidence and proposed change while continuing independent work.

Use copied fixtures, preserve originals and save identities, and keep private content out of reports/Git. Respect tool permissions. A failed connection or unavailable original/reference measurement remains a documented gap.

## Required return

1. **Outcome:** validated candidate, unchanged baseline, compatibility blocker, unsupported requirement, or measurement blocked. Distinguish compatibility from performance.
2. **Reproduction:** exact build/settings, source revision/bundle hash, browser/renderer/runtime mode, scene/input sequence, CPU-load conditions and capture commands/URLs.
3. **Results:** baseline/candidate settings, each repetition and median/range, evidence paths, measurement definitions and invalid captures.
4. **Behavior:** movement/timing, busy scene, pause/menu/input, audio, saves and controller checks with pass/fail/untested and reference method.
5. **Changes:** files/functions, reason, focused tests, rollback and any shared impact.
6. **Recommendation:** which setting may be accepted, which remains experimental, limitations, blockers and the next useful action.

Save the detailed report and data before returning a concise summary. Do not describe guest-clock restoration as proven full-game fidelity or a prototype estimate as completed work.
