# Bombs and sliding connectors

This extension is one shared engine capability, used by decoded level data. It does not create a separate game for each map. Focus47 is the first original-game witness for this composition; its native input route reached Thriller48 with4,000additional points. Browser qualification and local activation remain separate acceptance steps.

Burning and collecting are graph operations. The initiating dot changes first; a changed dot visits its incident connectors in source order, and a changed connector visits both endpoints in order. The two change guards terminate cycles. A blast can burn an already collected component. It does not remove the links, sliding directions or grab permissions. Only the initiating bonus pickup awards points; propagation does not award each connected dot separately. White rings and protected waypoints retain distinct rules.

The original also keeps drawing state. Some dots and links are painted into a persistent background, while others retain foreground sprites after their bonus is collected or they burn. Spark travel destructively fills a centered6×6rectangle with the mapped field color. Explosion callbacks paint a crater and repeat some dot work. Repainting the entire live map every frame would restore pixels that the original erased or place links over a crater. The new renderer therefore seeds the original background, then applies its ordered paint journal. Reset replaces the journal and restores the original map; common animation clocks have their own lifecycle.

Original geometry and enhanced SVG presentation remain separate. Source frames determine collision, anchors and erase rectangles. Bonus-dot shadows require eight distinct source images; a single generic shadow loses their colored reflections. New SVG payloads retain those descriptor dimensions and anchors, using the existing smooth source-color contour fitter. Their shading is an approximation. The previously accepted46scene drawing branch remains unchanged.

For generation, store connector orientation and endpoint identity, fuse topology and starter permissions, dot bonus/burn/ring/protection state, actor programs and classes, plus the source optimization identity needed for drawing. A generator must validate initial bonus closure, reachability under color permissions, physical sliding hazards and timing windows. A graph path alone does not prove a playable solution. Search and replay should use legal held inputs and verify the full action/target/slide-arrival path over varied initial clock onsets.

Thriller48 is a separate join: its two fuse chains can remove straight wall segments. Source review found a required erased-wall paint before the crater callback, and the current wall atlas lacks those nonempty erased frames. Its actual bomb terminals touch neither the protected waypoint nor an EXendpoint, so it cannot serve as an original-game witness for burning those objects. That source coverage must not be described as observed48gameplay. Later moving dots, richer bomb/GO/actor compositions, guns, busters and slowdown retain separate gates.
