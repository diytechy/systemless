# Catalogue coverage audit

Expanded after the initial application-only scan, 2026-11-07. Nine HFS/HFS+ content/boot images were surveyed read-only;3192 file records,226 APPL candidates. All original image hashes again match before/after. The configured Star Trek disc remains an explicit partition-boundary reader limitation; its catalogue is not claimed complete or corrupt. Its installed game executable is already queued from002.

The type/folder/container audit found **Desk Invaders II** in001, omitted by an APPL-only filter because its Finder type is `dfil` and its resource fork contains DRVR. It is now a separate pending family:69 total, with architecture/desk-accessory launch requirements unverified until its own Sol worker. Two other dfil programs, Calculator and Chooser in Boot, are explicitly classified as system utilities. No game was declared unsupported merely for lacking APPL.

Container-like candidates use filename suffix or SIT Finder-type heuristics; all other Finder types remain counted for review. Eighteen candidates were recorded:

- Five Lemmings/Oh No! More Lemmings disk images in006, associated with those existing queued families.
- Boot Gold_Digger_1.3.0.sit, associated with Gold Digger; archive contents/version unverified.
- Boot Trash/Koji_the_Frog.SIT, an unverified-version archive variant; preserve it without replacing selected2.0.4 or its save identity.
- Serial-MReader utility archive, StuffIt tutorial sample, and four Java/runtime class ZIPs, classified by source location/name as tool/runtime containers.
- Five zero-data Recent Items references, not selected payload archives.

This does not claim recursive inspection of every archive or unidentified file type. No additional compressed-only game family was identified in this survey. Unknown archive-version/content requirements stay explicit and can be inspected by the assigned title worker. queue.json includes container_audit and associated_containers so these are not silently omitted. Top-level folders and Finder-type counts are in inventory.json. Unconfigured007/008 each contain only three housekeeping records and no application/container candidate in this scan.

The original APPL classification remains81 game executable candidates/variants plus145 aliases/helpers/utilities; Desk Invaders adds one non-APPL candidate. Launchability, performance and compatibility remain separate from this metadata inventory.
