# Isolated native progress export

Structured headless play now accepts `export_save_files: true`. After successful actions it writes file deltas into a fresh `save-files/` child of the diagnostic output. The default remains false. This supports checking later levels from progress actually earned in the original game.

The exporter fingerprints the loaded archive before guest initialization, then compares final user-save summaries including both fork hashes and metadata. It uses the existing snapshot encoding for both forks, file type, creator, Finder flags and creation/modification dates. A manifest records SHA-256 values and deletion paths and is written last. It creates a new directory, propagates write errors and retains incomplete evidence. It never discovers, imports, migrates or updates the desktop save store. Tests cover same-length writes with unchanged dates, metadata-only changes, new/deleted files, refusing an existing export, the explicit opt-in and unchanged default report shape.

All 16 save-store tests and five play-script tests pass. Test compilation took4 min 18 sec; the subsequent native build took19.88 sec, sequentially. Native progress01replayed Curves, Homer and Touchdown, entered Tenacity and passed 16,883 frontend / 17,481 guest ticks with zero budget exhaustion. All 140 earlier accepted screenshots are pixel-identical to the previous native binary. This is regression evidence, not an independent Macintosh oracle or performance comparison.

The real export contains exactly ClockWerx Scores and Settings, no deletions. Their private contents remain outside Git. A separate 8 MiB fixture applies only these game-written files to a copy of the preserved source. Both forks and represented metadata are verified for all nine files, including seven untouched game files. The original source image remains byte-identical. The first private adapter attempt stopped before writing because the runner's logical ClockWerx root differs from the on-disk Untitled volume name; the corrected mapping and rejected attempt are retained.
